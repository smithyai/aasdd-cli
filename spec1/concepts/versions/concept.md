## Versions domain

Types representing known AASDD methodology versions.

### VersionEntry

A single known AASDD methodology version with a summary of its changes.

#### Properties

| Name | Type | Description |
| ---- | ---- | ----------- |
| `version` | text | The AASDD version string (e.g. `v1`). |
| `summary` | text | A one-sentence description of what was introduced in this version. |
